# Installation

## Prerequisites

- Node.js 18 or later
- React 19 or later
- [shadcn/ui](https://ui.shadcn.com/docs/installation) already set up in the app that will consume the kit

## Using the shadcn CLI

Once shadcn/ui is set up, install a component from this registry:

<InstallCli template />

Replace `[COMPONENT]` with a name from `/docs`, for example `model-select` or `prompt-input`.

Locally the origin is `http://localhost:3000`. After deploy, set `NEXT_PUBLIC_SITE_URL` to your site.
