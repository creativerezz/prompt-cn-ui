## Component API

### ModelSelect

| Prop          | Type                      | Default          | Description                          |
| :------------ | :------------------------ | :--------------- | :----------------------------------- |
| models        | ModelOption[]             |                  | List of models to show               |
| value         | string                    |                  | Selected model id                    |
| onValueChange | (id: string) => void      |                  | Called when the user picks a model   |
| placeholder   | string                    | "Select model"   | Label when nothing is selected       |
| disabled      | boolean                   | false            | Disables the trigger                 |
| className     | string                    |                  | Extra classes on the trigger button  |

### ModelOption

| Property | Type   | Description        |
| :------- | :----- | :----------------- |
| id       | string | Stable model id    |
| label    | string | Display name       |
| provider | string | Optional subtitle  |
