# Model Context Protocol

MCP lets Cursor (and other tools) read this registry so you can add components from chat.

## Cursor

1. Create `.cursor/mcp.json` in the **consumer** project (not this kit)
2. Add this server

<CodeBlock
  language="json"
  code={`{
    "mcpServers": {
        "${kit.name}": {
        "description": "${kit.name} registry",
        "type": "stdio",
        "command": "npx",
        "args": ["-y", "shadcn@canary", "mcp"],
        "env": {
            "REGISTRY_URL": "${getRegistryOrigin()}/c/registry.json"
            }
        }
    }
}`}
/>

3. Restart Cursor
